MURTUZA HUSAIN - PORTFOLIO
==========================

HOW TO OPEN
  1. Unzip this folder.
  2. Double-click index.html. It opens in Chrome, Edge, Firefox or Safari.
  (Internet is only needed for the Inter font. Without it the page uses your system font.)

WHAT TO KNOW
  - The first screen is a welcome screen. Tap or click anywhere to open the portfolio.
  - The "Night" button in the top bar switches between the red theme and a low-glare night theme.
    The choice is remembered in the browser.
  - The ID card in the About section can be dragged sideways to swing.

FILES
  index.html                          the page (all text lives here)
  css/style.css                       design (colours are the variables at the top)
  js/main.js                          welcome screen, theme switch, ID card, form
  assets/murtuza.jpg                  hero photo
  assets/murtuza-id.jpg               ID card photo
  assets/Murtuza_Husain_Resume.pdf    the resume people view and download
  assets/resume-preview.jpg           picture of the resume shown in the Resume section

UPDATING YOUR RESUME LATER
  Replace assets/Murtuza_Husain_Resume.pdf with the new PDF (same file name).
  The preview picture is a screenshot of page 1: replace assets/resume-preview.jpg too.

PUTTING IT ONLINE (FREE)
  Netlify: go to app.netlify.com/drop and drag this whole folder onto the page.
  Vercel: upload the folder as a new project (framework: Other).
  You then get a link you can send to recruiters.

CONTACT FORM
  There is no mail server, so "Send Message" prepares the message and offers
  "Open in Gmail" / "Copy message". To receive messages directly, connect the form
  to a service such as Formspree and put its URL in js/main.js.

GITHUB BUTTONS
  FuelFind, ShieldHer and SECMS link to their own repositories. The other project
  cards link to your GitHub profile. Replace the link in index.html when you have
  the exact repository addresses.
